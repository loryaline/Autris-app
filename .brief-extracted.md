# 1. Vision produit
Autris est un outil tout-en-un pour les romanciers francophones : world building, planification, rédaction et gamification. Un mix entre Notion (flexibilité) et Fortelling (structure narrative), avec Autarie l'otarie 🦭 comme compagnon unique et permanent.
Cible : romanciers francophones, tous niveaux, 18–45 ans
Différenciateur : seul outil couvrant le cycle complet (WB → planif → rédaction → soumission) + gamification + communauté
Pas d'IA en V1 — toutes les suggestions d'Autarie sont des règles logiques déterministes

## 2.2 Système de collection — principe général
En travaillant dans différents contextes d'Autris (genre du roman, world building, écriture nocturne, sessions longues…), Autarie explore un monde fantastique parallèle et ramène des items. La découverte est une vraie surprise — jamais annoncée à l'avance.
Ce qu'on N'a PAS
Aucun objet flottant autour d'Autarie — visuellement propre et non distrayant
Aucune notification pendant l'écriture — la découverte attend l'auteur
Aucune pop-up à la fermeture du Pomodoro
Ce qu'on A
Une carte discrète sur la home page (dashboard) quand une condition est remplie
L'auteur clique pour révéler l'item à son rythme — micro-animation pop (2s)
L'item rejoint la collection silencieusement — équipable quand l'auteur le souhaite
La collection est accessible depuis "Ma collection" dans le dashboard

# 3. Éditeur de profil Autarie
Autarie personnalisée devient l'identité visuelle de l'auteur sur le forum, l'Aoutris, le leaderboard et tout espace public. Plutôt qu'une photo ou un avatar générique, chaque auteur compose son Autarie unique depuis ses items débloqués.

## 3.2 Apparition sur le forum
Chaque post et commentaire affiche la photo de profil Autarie (32px)
La page de profil public affiche Autarie en grand (64px) + vitrine + stats

# 4. Calendrier d'activité multi-couleurs
Le calendrier type GitHub évolue — chaque case peut afficher plusieurs couleurs selon les activités du jour. Un auteur qui travaille sur les 3 zones (world building + rédaction + planification) voit un calendrier vraiment vivant et coloré.
## 4.1 Couleurs par activité
Cases multi-activités : la case est divisée horizontalement (haut/bas) entre les 2 couleurs dominantes
3 activités dans la journée : split en diagonale ou couleur mixte selon l'intensité
Intensité : plus l'activité est longue, plus la couleur est saturée (4 niveaux comme GitHub)

# 5. Personas & onboarding
Onboarding — 5 étapes
Accueil : Autarie (idle) + 3 chiffres clés + option "passer" pour les avancés
Persona : 4 profils, bouton Continuer désactivé sans sélection
Projet : titre (requis), genre → active les catégories WB correspondantes
Template narratif : libre / 3 actes / Snowflake / Save the Cat / Voyage du héros / "Autarie suggère" (règles logiques)
Objectifs : mots/session avec calcul temps réel, fréquence, durée Pomodoro
Écran final : badge "Première ligne" + 3 portes d'entrée (Écrire / Personnages / Planifier)

# 9. Architecture des modules
## 9.1 World building
Fiches : images uploadables (portrait, carte, illustration) via Supabase Storage
Post-its par catégorie — idées visuelles drag & drop
Liens entre fiches : perso ↔ lieu ↔ faction ↔ événement

## 9.2 Planification — 4 vues synchronisées
Tableau chapitres : colonnes drag & drop, ajout colonnes perso, couleurs de cases/lignes, gras/italique
Colonnes défaut : Ch. · Thème · Tempo · Synthèse · Scènes · Éléments clés · Arc · Nœud narratif · Statut
Outline par chapitre/scène : dépliable, synchronisé avec le tableau
Post-its Miro : couleurs, drag & drop, accessibles depuis l'éditeur en overlay
Diagramme de Gantt : timeline visuelle, milestones, deadline
Milestones : Envoi bêta-lecture · Correction v1 · Salon · Soumission éditeur · Custom
Sync optionnelle Google Calendar + iCal (Pro)
## 9.3 Rédaction — éditeur TipTap
3 panneaux fermables : Structure (gauche) · Contexte (droite, 4 tabs) · Pomodoro (haut)
Mode focus : bouton ⤢ — masque tout sauf le texte
Panneau Contexte : Info (stats) · Scènes · Versions · World
Toolbar : Gras · Italique · Souligné · H1 · ¶ · Liste · " · Ω (caractères spéciaux FR)
Barre de statut 30px : Autarie 🦭 (avec skin actif) · Pomodoro · Mots/Objectif · XP · Streak

Points critiques
Découverte items : carte HOME UNIQUEMENT — jamais dans l'éditeur ni pendant l'écriture
Aucun item ne flotte autour d'Autarie dans l'interface
Comptage Aoutris : trigger serveur UNIQUEMENT — jamais modifiable frontend
Thème UI : CSS variables sur l'ÉDITEUR UNIQUEMENT
Bannière Aoutris : HOME UNIQUEMENT
WB : project_id (pas novel_id) — partagé entre romans d'une saga
Downgrade : lecture seule — jamais de suppression
Conflits sync : résolution MANUELLE — jamais last write wins silencieux
daily_activity.wb_activity = true si au moins 1 fiche WB modifiée dans la journée
items_catalog et lore_pages : tables publiques sans RLS, gérées par l'équipe Autris
Aucune IA en V1 — toutes les suggestions = règles déterministes
